TinyPNG / macOS

首次打开，需要在系统设置中确认

如果 macOS 提示“Apple 无法验证 TinyPNG”或“已阻止 TinyPNG 以保护 Mac”，请按以下步骤允许打开。通常仅首次打开需要确认。

  1. 将 TinyPNG 拖到 Applications（应用程序）

    回到 DMG 窗口，将 TinyPNG.app 拖到 Applications 文件夹，再从“应用程序”中打开 TinyPNG。

  2. 出现阻止提示后，先关闭提示

    接着打开“系统设置”，进入“隐私与安全性”，向下滚动到“安全性”区域。

  3. 找到 TinyPNG，点击“仍要打开”

    你会看到“已阻止 ‘TinyPNG’ 以保护 Mac”等提示，右侧有“仍要打开”按钮。

  4. 完成系统确认，然后点击“打开”

    按提示使用 Touch ID 或输入 Mac 登录密码，随后在确认窗口点击“打开”，即可启动 TinyPNG。

 → 系统设置 → 隐私与安全性 → 安全性 → 仍要打开

打开“隐私与安全性”

浏览器若询问是否允许打开“系统设置”，请选择允许。如果按钮没有响应，请按上面的路径手动打开。

没有看到“仍要打开”？

再尝试打开一次“应用程序”中的 TinyPNG，然后立即回到“系统设置 → 隐私与安全性”，向下滚动查看“安全性”区域。该按钮通常只会在被阻止后的约一小时内显示。

请只对你确认来源可信的 TinyPNG 执行此操作。

Apple 官方说明：在 Mac 上安全地打开 App（需要联网）。本指南的操作步骤可离线阅读。
